## ◈ Featured Projects

<details>
<summary><strong>◈ Credit Card Fraud Detection System</strong></summary>

<br/>

An end-to-end anomaly detection pipeline for identifying fraudulent financial transactions in highly imbalanced datasets. The system applies Gaussian density estimation alongside ensemble classifiers, incorporating feature engineering over transaction metadata to maximize precision-recall performance in a production-grade evaluation framework.

| Attribute | Details |
|:---|:---|
| **Stack** | Python, Scikit-learn, XGBoost, Pandas, NumPy, Matplotlib |
| **Scale** | Trained and evaluated on 284,807 transaction records |
| **Performance** | High precision-recall AUC on imbalanced class distribution |
| **Security** | No PII; synthetic/anonymized feature space |
| **Impact** | Demonstrates real-world fraud detection pipeline applicable to fintech systems |
| **Repository** | [![GitHub](https://img.shields.io/badge/View_Repository-6d28d9?style=flat-square&logo=github&logoColor=white)](https://github.com/Harshal-yad) |

**Engineering Approach:** The core challenge was extreme class imbalance (0.17% fraud rate). The system addresses this through cost-sensitive learning, threshold calibration, and evaluation via F1, precision, and recall rather than raw accuracy — a critical distinction for safety-critical classifiers.

<br/>
</details>

<details>
<summary><strong>◈ Collaborative & Content-Based Recommender System</strong></summary>

<br/>

A hybrid recommender system implementing both collaborative filtering via matrix factorization and content-based filtering using item feature vectors. The architecture mirrors production recommender pipelines used in streaming and e-commerce platforms, with explicit handling of the cold-start problem.

| Attribute | Details |
|:---|:---|
| **Stack** | Python, TensorFlow, NumPy, Pandas |
| **Scale** | Multi-thousand user-item interaction matrix |
| **Performance** | Optimized via mean squared error on held-out user ratings |
| **Security** | Simulated dataset; no real user data involved |
| **Impact** | Full implementation of industry-standard recommendation architecture |
| **Repository** | [![GitHub](https://img.shields.io/badge/View_Repository-6d28d9?style=flat-square&logo=github&logoColor=white)](https://github.com/Harshal-yad) |

**Engineering Approach:** The collaborative filtering component learns latent user and item embeddings through gradient descent on the interaction matrix. Content-based filtering is combined via weighted scoring, producing recommendations robust to sparsity and cold-start scenarios.

<br/>
</details>

<details>
<summary><strong>◈ Deep Reinforcement Learning Agent</strong></summary>

<br/>

An implementation of a deep Q-network (DQN) agent trained to solve sequential decision-making environments. The project covers the full RL pipeline: environment setup, replay buffer, epsilon-greedy exploration, target network stabilization, and convergence analysis.

| Attribute | Details |
|:---|:---|
| **Stack** | Python, TensorFlow/Keras, NumPy, OpenAI Gym |
| **Scale** | Trained over thousands of episodes with experience replay |
| **Performance** | Stable convergence demonstrated via reward curve analysis |
| **Security** | Isolated simulation environment; no external dependencies |
| **Impact** | Foundation for real-world RL applications in robotics and autonomous systems |
| **Repository** | [![GitHub](https://img.shields.io/badge/View_Repository-6d28d9?style=flat-square&logo=github&logoColor=white)](https://github.com/Harshal-yad) |

**Engineering Approach:** Implemented experience replay and a fixed target network to stabilize training — addressing the correlation and divergence issues that plague naive Q-learning with neural networks. Hyperparameter sensitivity was systematically analyzed across learning rate, discount factor, and exploration decay.

<br/>
</details>

<details>
<summary><strong>◈ Healthcare Anomaly Detection System</strong></summary>

<br/>

A Gaussian-model-based anomaly detection system designed for identifying outlier patterns in healthcare metrics. The project implements multivariate density estimation to flag anomalous readings that may indicate equipment faults or critical patient events.

| Attribute | Details |
|:---|:---|
| **Stack** | Python, NumPy, Scikit-learn, Matplotlib, Seaborn |
| **Scale** | Multivariate feature space with labeled anomaly evaluation |
| **Performance** | Threshold tuned against F1 score on validation anomaly set |
| **Security** | Synthetic dataset; no patient data used |
| **Impact** | Applicable to ICU monitoring, wearable health systems, and diagnostic pipelines |
| **Repository** | [![GitHub](https://img.shields.io/badge/View_Repository-6d28d9?style=flat-square&logo=github&logoColor=white)](https://github.com/Harshal-yad) |

**Engineering Approach:** The system models the joint feature distribution as a multivariate Gaussian and evaluates each sample against a learned density threshold. Epsilon was selected by maximizing F1 on a cross-validation set containing labeled anomalies, reflecting real deployment constraints.

<br/>
</details>
